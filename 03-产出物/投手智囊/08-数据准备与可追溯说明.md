# 投手智囊 · 数据准备与可追溯说明

> 版本：v0.2，2026-09-17。本文只记录已核验事实、复现步骤和明确限制；平台配置截图在《平台配置与版本记录》中单独登记。

## 1. 数据血缘

```text
ad_performance.csv（飞桨公开数据集55268）
  → explore_data.py：字段/缺失/分组探查
  → build_benchmark.py：真实转化端与流量质量分组分位数
  → synthesize_curve.py：合成曝光端参数与出价曲线
  → verify_monotonic.py：分位数、范围、单调性校验
  → KB-基准库-01/02/03：助手检索材料
  → bid_simulator.py：当前出价相对同组锚点的确定性仿真
  → verify_bid_simulator.py：拒绝分支、预算约束、人工手算与可复现性校验
  → KB-基准库-04/规则08：首测档和相邻测试带
```

## 2. 真实与合成边界

- KB-基准库-01：飞桨数据中的历史转化端、注册率、UV、停留时长、访问深度和搜索量；不能当作当前平台报价。
- KB-基准库-02：项目合成的 CTR、CPM、CPC、CVR 行情锚点；每格 30 个伪样本、对数正态噪声 σ=0.18、随机种子 42，明确声明不代表真实大盘。
- KB-基准库-03：share(r)=r²/(r²+1) 的合成出价曲线；只用于方向和相对倍数解释。
- KB-基准库-04：`bid-sim-v1.1` 离线确定性仿真输出。输入使用KB-02合成锚点与项目假设，仅支持同单位CPM/CPC；不代表平台实时竞价或最优出价。

## 3. 字段和单位约束

| 数据 | 关键字段/指标 | 单位与限制 |
|---|---|---|
| 原始 CSV | 渠道、日均UV、注册率、搜索量、访问深度、停留时长、订单转化率、合作方式、广告类型、素材类型 | 原始字段；率值需确认百分数/小数刻度 |
| KB-01 | 订单转化率、平均注册率、日均UV、停留时长、访问深度、平均搜索量 | P25/P50/P75；样本不足组仅作方向参考 |
| KB-02 | CTR、CPM、CPC、CVR | CTR/CVR 为百分比展示；计算器用小数；CPM/CPC 为元 |
| KB-03 | 出价倍数、曝光倍数、成本倍数、转化倍数 | 理论相对倍数；固定预算下不保证同倍数增长 |
| KB-04 | 当前出价、锚点位置、候选倍率、三情景结果、测试带、原因码 | 合成仿真；只用于首轮相邻档测试；oCPM/CPA无同口径锚点时拒绝 |

## 4. 复现命令

在 `04-协作区/03-数据脚本/` 目录执行：

```bash
python3 explore_data.py
python3 build_benchmark.py
python3 synthesize_curve.py
python3 verify_monotonic.py
python3 bid_simulator.py
python3 verify_bid_simulator.py
```

验收时需保存：命令执行时间、Python 版本、输入文件名与行数、输出文件、校验报告和异常说明。不得手工修改脚本产出的数值。

## 6. 数据入库前检查

- 文件名、版本号、更新时间和来源写在每份 KB 的口径说明中。
- 真实、合成、理论曲线三种口径不放在同一张演算表中。
- 表格切片后标题和单位仍完整；随机抽查至少每个 KB 两个切片。
- 发现数字异常时回到脚本和原始数据排查，不直接改库内数字。
- 压缩上传包更新后，抽查规则、KB-02数字、KB-04限制和来源声明各至少一个检索问句，避免上传成功但召回失败。
