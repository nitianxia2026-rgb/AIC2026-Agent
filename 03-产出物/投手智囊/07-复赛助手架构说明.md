# 投手智囊 · 复赛助手架构说明

> 版本：v0.2 设计稿，2026-09-12。复赛平台形态为“助手”，不是可视化工作流；状态机写入系统提示词，并由知识库、计算器、MCP 工具和对话测试共同实现。工具能力的函数名与参数见《平台工具能力记忆库》。系统提示词当前仍为 v0.1 工具路由增补稿，待实测后冻结 v0.2。

## 1. 架构总览

```text
用户自然语言
  ↓
节点1 需求解析与一轮追问
  ↓
规则库检索 ───────┐
  ↓               │
节点2 渠道/竞价 ──┤
节点3 人群定向 ────┤→ 基准库检索 → 计算器
  ↓               │
节点4 漏斗正向/逆向演算
  ↓
节点5 出价单调性与预算约束自检
  ↓（目标过高时回推节点2/5）
节点6 预算分配与文字素材 brief
  ↓
按需工具层：搜索/竞品/图表/思维导图/导出/概念图
  ↓
四段式回答或“图表/文件附件 + 四段式说明”
```

## 2. 节点输入输出契约

| 节点 | 输入 | 输出 | 主要依据 | 异常处理 |
|---|---|---|---|---|
| 1 需求解析 | 用户原话 | 行业桶、预算、目标、区域、假设 | 规则库01 | 缺项一次问齐；仍缺则声明默认 |
| 2 渠道/竞价 | 节点1结果 | 主渠道、备选、竞价方式、理由 | 规则库02/03、基准库02 | 平台规则未知则只给类型建议 |
| 3 人群定向 | 行业、目标、区域 | 核心组、测试组、地域、时段原则 | 规则库04、基准库01 | 无时段数据只给定性建议 |
| 4 漏斗演算 | 预算或目标、同一分组参数 | 曝光/点击/转化或逆向预算区间 | 基准库02、计算器 | 缺参数或跨格时停止输出数值 |
| 5 自检 | 出价、预算、曲线 | 单调性、边际成本、预算封顶提示 | 规则库05、基准库03 | 条件不一致则重算或降级 |
| 6 收口 | 前五节点结果 | 预算比例、三个文字素材方向、指标 | 规则库06/07 | 越界/合规风险先拦截 |
| 工具路由 | 用户意图和节点结果 | 工具调用及附件 | 工具能力记忆库 | 缺参数/失败则说明并降级 |

## 3. 检索、计算和引用链

1. 规则类问题优先检索规则库；行情和演算参数只检索基准库。
2. 演算参数必须来自同一行业×广告形式×素材格；KB-01真实历史数据不能与KB-02合成参数混算。
3. 计算器只负责乘除、比例、汇总和单位换算；公式和参数必须先由知识库确定。
4. 输出数字时引用到文档、分组和字段；找不到字段就改为定性建议。
5. 所有区间标记“建议区间，非精确预测”；KB-02额外标记“按行业常见水平估算”。
6. 工具只在明确触发时调用；工具返回的实时信息不得覆盖知识库基准数字。

## 4. 状态转移与回推

- 正常路径：1 → 2/3 → 4 → 5 → 6。
- 节点4判断预算对应的中值转化低于用户目标：回推节点2（换渠道/竞价）或节点5（比较出价带），然后再回节点6；不得跳过节点4直接给预算分配。
- 用户补充了品类、预算或目标：从节点1重新解析，保留已确认字段并声明变更。
- 用户要求投后复盘、图片生成或平台代投：转规则库07的范围说明，不伪装已实现。
- 用户主动要求查资料/竞品/可视化/流程图/下载文件：进入工具路由；一轮最多调用两类工具，先确认参数再调用。

## 5. 复赛平台配置映射

| 产品设计 | 平台配置 |
|---|---|
| 六节点状态机 | 系统提示词流程约束 |
| 规则方法论 | 文档知识库，按层级切分 |
| 基准参数 | 文档知识库，合成/真实口径分开 |
| 算术计算 | 内置计算器 |
| 实时资料 | Web Research（仅外部背景，标注日期/URL） |
| 竞品观察 | 值得买 product_search_list/content_summary_search/compare_price |
| 解释性图表 | generate_funnel_chart / generate_line_chart / generate_bar_chart |
| 结构表达 | generate_mind_map / generate_flow_diagram |
| 交付附件 | markdown_to_document；概念图可用 text_to_image |
| QA 语料 | 交付区两份 Markdown 文档化问答片段，不使用不可挂载的 QA 类型库 |
| 节点测试 | 对话测试集和人工验收表 |

复赛无可视化工作流，因此必须保存平台配置截图和测试记录，作为“实现架构”证据。新增 MCP 不是替代状态机，而是按触发条件挂接的工具路由层。

## 6. 架构验收标准

- 任一完整投前问题都能回显需求卡并按 1→6 顺序回答。
- 缺少必填项时最多追问一轮；用户拒答时明确假设。
- 数字均可追溯；计算器调用可在平台记录或截图中证明。
- 无时段数据、跨库混算、固定预算曲线、敏感行业等负面场景均能降级或拒答。
- 复赛版本不输出完整投后诊断或 API 执行结果；只有用户明确要求且工具通过验收时，才生成“概念示意图”，不冒充真实广告素材。
- 工具调用不改变复赛范围：搜索和竞品仅作投前背景，图表/思维导图/导出属于表达增强；图片生成仅作概念示意。
