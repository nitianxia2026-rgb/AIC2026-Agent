# 投手智囊 · 复赛 90 分钟操作 Runbook

> 版本：v0.1，2026-09-11。正式平台、账号和监考事实以 `01-赛事实录/复赛通知-2026-34号.md` 为准；本表用于计时演练和比赛当天执行。

## 1. 预上传期（9/15–9/18）

- [ ] 登录正式环境，确认账号、模型、知识库数量和计算器可用。
- [ ] 上传最终版 KB-基准库和 KB-规则库；优先 Markdown，若有数量限制按队长确认的合并包替代。
- [ ] 每个库随机抽查至少 2 个切片：标题完整、表格未截断、来源和单位保留。
- [ ] 记录库名、文件版本、上传时间、平台限制和截图。
- [ ] 不在预上传期依赖会被清除的助手配置；提示词和助手配置留到正式比赛按计时流程执行。

## 2. 比赛 90 分钟分配

| 时间 | 动作 | 完成标志 |
|---|---|---|
| 0–8 分钟 | 登录、核对环境、确认知识库 | 三库可检索、计算器可见 |
| 8–18 分钟 | 创建助手、填写名称和开场白 | 助手保存成功 |
| 18–32 分钟 | 粘贴系统提示词 v0.2、选低温模型 | 提示词完整，无截断 |
| 32–40 分钟 | 挂载规则库、基准库和计算器 | 配置截图/记录完成 |
| 40–62 分钟 | 跑核心测试 T01–T06 | 主流程和数字纪律通过 |
| 62–75 分钟 | 跑负面测试 T07–T12 | 追问、拒答、降级通过 |
| 75–84 分钟 | 修正明显提示词或开场白问题 | 只做小改，重新跑阻断题 |
| 84–90 分钟 | 保存、截图、复核提交状态 | 助手可访问、无未保存提示 |

## 3. 阻断测试

至少完成：奶茶店正向演算、月度目标逆向预算、出价翻倍、缺三要素追问、敏感行业拒答、无时段数据降级、保证销量拒答、跨库口径不混算。

## 4. 备用方案

- 知识库挂载数量不足：保留规则库01/02/05/07和基准库02/03，合并低优先级规则为一个 Markdown 索引包。
- PDF 或复杂表格解析异常：使用 Markdown 版本，不临场转换格式。
- 计算器不可用：不得心算给出具体数字，改输出公式、参数来源和定性建议，并记录为平台问题。
- 模型响应过慢：切换已在演练中通过的候选模型，不临场尝试未测模型。
