# 出价API `bid_simulate` · 比赛日挂载速查

> 来源：《平台API与MCP挂载说明-v1.md》（06-试搭物料）浓缩。密钥不入任何文件。

## 五步挂载

1. 助手工具页 → 创建API工具；
2. 工具名称：`投手智囊-出价测试带`；
3. Schema：从URL导入 `https://toushou-bid-sim-api.onrender.com/openapi.json`；
4. 鉴权方式：API Key；Header名称 `X-API-Key`；密钥只填平台鉴权区，不截图不入档；
5. 解析后应只见 `bid_simulate`／post／`/bid-simulate`；点"测试"通过 → 保存 → 挂到助手。

## 挂载后快速验证

J07a 问法（餐饮信息流/CPM/日预算500/出价20/目标加微信/消耗60%）→ 追问回传时答"是" → 应返回：主计划保持20元、首测20元、相邻带18—22元。

## 异常处置

- 解析失败/超时：重试一次；仍失败 → **摘除该工具即可**。提示词已内置 KB-04＋计算器离线兜底，无需改任何配置，回答会自动注明"离线仿真兜底"。
- 已知行为：平台把空白布尔序列化为 `false` 会返回 TRACKING_NOT_READY（回传未就绪拒绝）——属正常业务拒绝，追问用户回传状态即可，不算故障。

## 明确不做

- REST 地址不填 MCP 配置框（本服务不是 MCP Server）；
- 解析结果出现 `healthz` 或未知 operation 时不保存，先重导 Schema；
- 不把密钥写进截图、聊天或提交材料。
