# KB-规则库-05 · 出价单调性规则

> 管什么：判断调高或调低出价时，理论曝光方向、边际成本和预算约束是否合理。
> 给哪个节点用：节点5（自检）。版本：v0.1，2026-09-11。

## 出价提高会怎样？（加价能不能多曝光／出价翻倍效果如何／要不要抬价）

1. 先确认用户比较的是同一广告形式、同一人群、同一素材和同一预算条件；条件变化时不能把差异只归因于出价。
2. 查 KB-基准库-03 的出价倍数 → 曝光倍数 → 成本倍数曲线。
3. 理论方向必须满足：出价上升，竞争份额和可获得曝光不下降；但增幅边际递减。
4. 成本增速明显快于曝光增速 → 提示边际成本恶化，优先优化素材 CTR、落地页 CVR 或定向，而不是继续抬价。
5. 输出建议出价带或测试档位，不给“最佳出价”单点承诺。

## 固定预算时为什么不一定多曝光？（预算不变还加价／钱花完了怎么办）

KB-基准库-03 描述的是理论竞争份额曲线，不等于固定预算下必然获得同倍数曝光。固定日预算时：

- 出价提高可能更快消耗预算，全天实际曝光增幅会小于理论曲线，甚至因单次成本上升而无法增加总曝光。
- 回答必须分成“理论竞争力变化”和“固定预算约束”两层。
- 不得同时声称“预算不变、单价更高、曝光一定按曲线倍数增加”。
- 若用户目标是增加转化，应同步检查 CTR 和 CVR；出价只解决竞争机会，不保证转化质量。

## 出价倍数怎么演算？（从两块涨到四块／提高50%会怎样）

示例：用户把出价从 2 元提高到 4 元，其他条件不变。

1. 计算器计算出价倍数：`4÷2=2.0`。
2. 查 KB-基准库-03：2.0×出价对应理论曝光约 1.60×、成本约 3.20×。
3. 输出：“理论竞争份额提高，曝光方向上升，但成本上升更快；固定预算下实际曝光增幅可能明显低于 60%。”
4. 建议用 1.0×、1.5×、2.0×分档测试，保持素材和定向不变；不得把表中倍数说成保证结果。

## 曲线没有对应倍数怎么办？（出价涨20%／倍数不在表里）

- 曲线只列 1.0、1.5、2.0、2.5、3.0 倍时 → 引用最接近的上下档作为范围，不自行插值造精确数字。
- 超过 3.0 倍 → 明确超出知识库曲线范围，只能判断方向，不能给曝光或成本倍数。
- 低于基准价 → 当前表没有可靠下行倍数时，只说明竞争份额可能下降，并建议小步测试。
- 查不到基准出价 → 不能把 CPC、CPM 或 CPA 当作同一“基准价”互换。

## 单调性自检不通过怎么办？（结果矛盾／提价后曝光反而降低）

1. 先检查是否混用了不同预算、素材、人群、时间或竞价方式。
2. 再检查百分数、小数、元和千次展示单位。
3. 重新调用计算器；仍矛盾则不输出数值，说明数据条件不足。
4. 实际投放中提价后曝光下降不等于理论失效，可能存在预算耗尽、流量波动、素材衰退或审核状态变化；复赛版不做归因诊断。

## 口径与依据

本规则采用 AuctionNet“出价影响获胜机会与成本”的逻辑骨架，但具体曲线为项目合成模型。数值只从 KB-基准库-03 读取，必须注明“理论曲线、非精确预测；固定预算下受预算封顶影响”。
