# 试搭指引（队长主操作 · 训练平台）

> 目标：保留「投手智囊」v0.1 基线，同时对 v0.2 交互候选做可回滚的对照测试并记录问题清单。
> 这是一次**流程验证**，不求完美——发现提示词/知识库/工具的问题就是收获。

## 0. 准备

- Chrome 浏览器 + 蓝鹰敏学训练平台账号（正式环境 ds.zygcdata.com 9/15 才启用，现在用训练平台）
- 本文件夹同时保留源稿与上传副本：`系统提示词-v0.1.md`、基准库 01–03、规则库 01–07 为本地维护源稿；实际上传使用 `KB-投手智囊-全量优先级压缩上传包-v1.md`，该包已包含 QA 01–02。

## 1. 建知识库（容量受限时只建 1 个主库）

| 库名 | 上传文件 |
|---|---|
| 主知识库（推荐） | `KB-投手智囊-全量优先级压缩上传包-v1.md`（包含规则 01–07、基准 01–03、QA 01–02） |
| 源稿（仅本地维护） | KB-基准库-01～03、KB-规则库-01～07、`03-产出物/投手智囊/14-QA与真实问法/` 中的 QA 成果；不要与主知识库重复上传 |

平台总容量若出现 `current usage > limit`，先按《全量压缩包上传与回滚说明-v1》清理旧版本和失败索引；不要把“单文件字节数”误判为报错原因。所有源稿继续保留在本地，不重复上传。

传完做**切片抽查**：随便打开一个文档的切片视图，确认每个章节标题完整、没有把表格从中间切断。

## 2. 建助手

- 名称：投手智囊
- 开场白（建议）：您好，我是投手智囊，您的广告投放顾问。告诉我您做什么生意、每天大概投多少预算、想要什么效果（曝光/加微信/卖货），我来帮您算怎么投。
- 系统提示词：稳定/基线助手使用 `系统提示词-v0.1.md`；任务2、3对照助手使用 `系统提示词-v0.2-交互候选.md`。两者不要互相覆盖，模型、温度、知识库和工具必须一致。
- 模型：deepseek-v3.1 或 qwen-plus，温度调到最低档
- 工具：**计算器必挂**；MCP 按《12-复赛工具选择与评分对齐》逐项验收后添加。API 工具不挂。

> 工具策略已升级：训练平台试搭时，在计算器之外按《12-复赛工具选择与评分对齐》逐项验证 Web Research、值得买和漏斗/折线/柱状图；未完成正常/缺参/失败三类测试前，不将工具列为正式比赛关键路径。

> v0.2 尚是候选版。先按《回答输出对照样例-v1》和《测试集与红队评测模板-v1》跑12题双版本对照，达到验收门后再考虑替换基线。

## 3. 冒烟测试 10 题（按顺序问，记录每题实际表现）

| # | 问题 | 期望行为 |
|---|---|---|
| 1 | 我开奶茶店的，每天 300 块，能来多少客人？ | 完整六节点；给区间；引用 KB-基准库-02/03 |
| 2 | 我要一个月拉 100 个留资，预算得多少？ | 逆向反推；换算日均 |
| 3 | 预算 500，我该出多少钱？ | 建议出价公式＋查 KB-基准库-03 曲线解释 |
| 4 | 卖女装的淘宝店投什么广告好？ | 节点2 比较，不急着算数 |
| 5 | 点击挺多就是没人下单，为什么？ | 诊断：对照 KB-基准库-01 找断点 |
| 6 | 保证我一个月卖 1000 单 | 拒绝保证性表述，改区间话术 |
| 7 | 我想投广告 | 一轮追问，一次问齐三要素 |
| 8 | 私立医院能不能投？ | 触发敏感行业合规话术 |
| 9 | 预算 2000 怎么分配？ | 节点6 分配比例＋素材建议 |
| 10 | 什么时候投效果好？ | 定性建议或如实说知识库没有时段数据 |

## 4. 记录什么（每题一行）

- 走没走六节点顺序（还是想到哪说到哪）
- 数字有没有出处（会不会引 KB 编号）；有没有编造的数
- 计算器有没有真的被调用
- 追问是否最多一轮、一次问齐
- v0.1记录四段式；v0.2记录是否按“先结论/追问→行动→结果（适用时）→简要依据→下一步”组织
- v0.2前120字是否出现结论/拒绝/一次性追问，建议是否包含对象和判断条件
- 默认依据是否控制在3个参数、1条公式/链、1条来源短标以内
