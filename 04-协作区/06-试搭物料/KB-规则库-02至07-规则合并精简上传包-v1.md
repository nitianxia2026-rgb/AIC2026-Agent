# KB-规则库-02至07 · 规则合并精简上传包

> 用途：平台容量受限时，替代单独上传规则库 02–07。规则源稿仍保留在同目录，源稿是维护依据，本文件是上传副本。版本：v1，2026-09-12。

## 全局口径（所有规则共用）

- 先完成需求解析，再依次执行：渠道/竞价 → 定向 → 数值演算 → 单调性自检 → 预算与素材收口。
- 具体数字只能来自对应基准库或计算器；查不到就说明缺口，不得用常识补造。
- KB-基准库-01 是飞桨真实历史的转化端/流量质量观察；KB-基准库-02 是合成曝光端行业锚点；KB-基准库-03 是理论出价曲线。三者不能跨库混算。
- 任何效果、曝光、转化均用“建议区间，非精确预测”；固定预算下不把理论曲线说成保证结果。

## 02 · 竞价方式判定（节点2）

1. 曝光、活动告知且不要求点击/转化：优先 CPM。
2. 访问页面、进店或阅读内容且转化链路未接通：优先 CPC。
3. 留资/下单且平台已有稳定转化回传：可建议 oCPM；不得说成只按成交付费。
4. 仅在平台明确支持按有效转化计费、转化定义和回传均确认时，才建议 CPA。
5. 未知回传能力：先给 CPC 小额验证，并说明满足条件后再评估 oCPM；不承诺成本或销量。
6. 日预算低于 300 元先只测一个主目标 3–7 天。用户未定义“效果”时，回到节点1一次问齐曝光/点击/留资/下单。

**公式纪律**：CPM 直接按千次展示；CPC 概念 eCPM≈CPC×CTR×1000；CPA 只有在平台按转化排序时才可作 eCPM≈CPA×CTR×CVR×1000 的概念解释；oCPM 不套统一公式。CTR 用小数。不同计费口径不能直接比较。

## 03 · 渠道适配（节点2）

- 主动获客、留资、卖货但用户未必搜索：信息流优先。
- 搬家、维修、培训报名、家装咨询等明确意图：搜索可主投或辅助。
- 目标是大范围曝光且日预算高于 1000 元：开屏只列备选；小预算或直接转化不优先。
- 日预算 <300 元：只选一个主渠道；300–1000 元：一个主渠道+一个小额测试；>1000 元：可做信息流+搜索组合。总预算先按周期换算日预算，无周期默认 7 天并声明假设。
- 行业适配：餐饮先测本地信息流；教育信息流获线索、搜索承接课程意图；电商新品/视觉商品信息流、品牌/品类词搜索；本地服务按需求强弱选搜索或信息流；家居建材信息流种草留资、搜索承接明确需求。
- 新计划小额试投 3–7 天，一次只改一个变量；不知道平台门槛、报价或学习期时，明确以后台规则为准。
- 具体行情只能查 KB-基准库-02 同一行业×形式×素材格，并注明合成估算口径。匿名渠道字段不得翻译成具体媒体。

## 04 · 人群定向建议（节点3）

按“必要限制 → 核心人群 → 测试人群”输出：先服务/履约范围及确有必要的限制，再用需求阶段描述核心人群，最后只放宽一个维度做 A/B。不得把匿名 ID、渠道编号或流量字段翻译成人群标签。

- 到店/配送业务按实际服务区；教育、家居按可服务城市/校区；全国电商排除无法配送或售后覆盖地区。
- 年龄/性别无产品依据就不限制；人群过窄每次只放宽一个限制，不用抬价替代定向优化。
- 时段没有真实小时数据，只能按营业、客服和履约时间定性建议，并设置两个时段测试组；不得编“某时段提升多少”。
- 强意图人群素材写清服务、差异和行动；泛兴趣先讲场景痛点和利益；本地业务写区域/到店条件，禁止“第一、最低、保证”等绝对词。
- 不接收手机号、身份证、设备 ID 等个人数据。KB-基准库-01 的 UV、停留、访问深度不能推导年龄、兴趣、地域或时段。

## 05 · 出价单调性自检（节点5）

- 仅在同一广告形式、人群、素材、预算条件下比较出价。查 KB-基准库-03 的“出价倍数→理论曝光倍数→成本倍数”。
- 理论上加价不应降低竞争份额/可获得曝光，但边际递减；成本增速快于曝光时，优先优化素材 CTR、落地页 CVR 或定向。
- 固定预算时，加价可能更快耗尽预算，实际全天曝光不保证按理论倍数增加。建议给出测试档位，不给最佳出价单点。
- 曲线无对应倍数：引用相邻档范围；超过 3 倍只说方向；低于基准价不造下行倍数；CPC、CPM、CPA 不互换基准价。
- 结果矛盾先检查预算、素材、人群、时间、单位和百分比，再用计算器重算；仍无法解释就不输出数值。

## 06 · 预算分配与素材 brief（节点6）

- 日预算 <300 元：一个主渠道/形式；300–1000 元：可从主投 70%+测试 30%起步；>1000 元：一个主投加 1–2 个测试方向。70/30 是测试起点，不是行业保证。
- 所有金额调用计算器。预算不足时，用 KB-基准库-02 同组参数正/逆向演算，给“提高预算”或“降低目标并优化 CTR/CVR”两条路径，不用抬价掩盖预算不足。
- 爬坡：先验证素材、追踪和落地链路，再每次只改一个变量；样本少不因单日波动大幅加预算。
- 每次输出 3 个文字 brief：问题解决型、场景利益型、信任证明型。每个含目标人群、痛点、主卖点、标题方向、行动指引；不虚构销量、评价、案例、资质。指标按目标选择：曝光看曝光/CPM，点击看 CTR/CPC，转化看 CVR/CPA。
- 复赛版只给投前观察计划，不假装完成投后日志诊断。

## 07 · 方法论与合规横切校验（所有节点）

优先级：合规隐私 > 数字与引用纪律 > 复赛六节点范围 > 个性化要求 > 表达风格。

- 拦截“第一、唯一、全网最低、百分百、保证有效、一定成交、零风险”等绝对化/保证性宣传，改成可核实事实。
- 医疗诊疗、药品保健品、金融投资、彩票博彩、成人用品：不提供渠道、出价、预算、定向或规避审核方案；只建议核对平台政策和资质，不能声称法律审查。
- 拒绝刷量、刷单、虚假点击、伪造转化、绕审核、代充值/代投；不复述个人联系方式或隐私数据。
- 复赛冻结版仅做投前决策：不连接广告 API、不生成真实人群包、不训练模型、不保证 ROI/销量。投后问题只给预防性检查项。
- 输出前检查：是否一轮问齐缺项；每个数字能定位到基准表/计算器；是否跨库混算；是否把理论曲线当保证；是否触发敏感行业/隐私/违规；是否越过复赛范围。任一不通过，删掉无依据内容并降级说明。
