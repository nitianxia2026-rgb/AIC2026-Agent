# KB-规则库-08 · 出价仿真与测试带规则

## 1. 何时启用

用户询问“当前出价应该提高还是降低、提高多少、如何做相邻档测试”时启用。普通预算漏斗仍走KB-02；只问机制但输入不足时，不强行运行仿真。

## 2. 先生成输入卡

```text
行业｜广告形式｜CPM/CPC｜目标｜日预算｜当前出价｜当前统计周期消耗比例｜回传状态（留资/下单必填）｜还缺什么
```

缺行业、广告形式、计费方式、目标、日预算、当前出价或消耗比例时一次问齐；留资/下单缺回传状态也要补问。不得自动填“消耗60%”“回传就绪”或“审核通过”。

## 3. 决策流程

1. 确认搜索用CPC，信息流/开屏用CPM；冲突时停止。用户填写的是oCPM目标成本或CPA出价时，不得套用CPM/CPC锚点，当前版本暂停仿真并说明需要同单位历史锚点。
2. 匹配KB-02同一行业×广告形式×素材分组的成本、CTR、CVR。
3. 查KB-02同组P50成本锚点，计算当前出价相对锚点的位置；再查KB-04中与预算、消耗状态和当前价位置相近的测试带。
4. 用计算器将倍率换成具体候选价，不让模型心算。
   - 倍率只能乘用户当前出价，不能乘KB-02锚点；锚点只负责定位，不能直接作为建议价。
5. 比较保守/基准/乐观情景，只推荐方向稳定的档位。
6. 输出首测档、相邻档、观察指标和停止条件；不输出“最佳出价”。
7. 用户只问调价时不主动追加曝光/点击/转化预测；“消耗比例”不能在统计周期和实花金额未知时改写成已花金额或剩余预算。

## 4. 必须暂停推荐的情况

- 当前出价、日预算、计费方式或消耗比例缺失；
- 留资/下单目标的转化回传状态未知或未就绪；
- 当前输入是oCPM目标成本或CPA出价，但没有同计费口径的成本锚点；
- 转化目标但回传未就绪；
- 广告仍在审核、链接异常或存在合规问题；
- 用户同时改变素材、人群、目标，无法把表现变化归因于出价；
- 三情景方向冲突明显。

暂停时仍要告诉用户“后台需要补哪项、补齐后如何比较”，不能只回复不能计算。

## 5. 面向用户的回答范式

```text
【出价测试卡】当前价__元｜建议先测__倍＝__元｜相邻带__–__元
【为什么】目标收益、成本和预算风险的平衡
【观察】消耗速度＋目标指标＋单位成本
【停止】预算消耗加快但目标指标未改善，或单位成本连续恶化
【边界】合成仿真，用于首轮测试，不代表平台最优出价
【继续完成】画三档对比折线图 / 整理可复制的Markdown测试计划
```

## 6. 禁止表述

- 不称“平台官方算法”“真实行业弹性”“训练后的最优价格”；
- 不把相对当前出价倍数说成相对市场基准；
- 不把KB-02 P50合成成本锚点称为平台底价或真实市场价；
- 不把oCPM目标成本、CPA出价与CPM/CPC成本锚点直接比较或换算；
- 不保证曝光、点击或转化增长；
- 不隐藏合成数据声明。
