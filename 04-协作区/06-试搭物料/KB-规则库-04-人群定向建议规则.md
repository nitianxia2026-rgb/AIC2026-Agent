# KB-规则库-04 · 人群定向建议规则

> 管什么：把品类、区域和目标转成可执行的人群、地域、时段及素材匹配建议，不生成虚构人群数据。
> 给哪个节点用：节点3（定向建议）。版本：v0.1，2026-09-11。

## 人群怎么定向？（广告投给谁／目标用户怎么选／人群包怎么设置）

按“必要限制 → 核心人群 → 测试人群”的顺序输出：

1. 必要限制：服务范围、履约范围、明显年龄限制和合规限制。只保留业务确实需要的限制，避免一开始过窄。
2. 核心人群：用需求阶段描述，如“近期关注装修”“正在搜索搬家服务”，不用知识库没有的精确人数或转化率。
3. 测试人群：放宽一个维度或更换一个兴趣方向，与核心组做 A/B 对照。
4. 不得把匿名特征 ID、数据集渠道编号或流量字段翻译成具体兴趣标签。

## 地域怎么圈？（投附近几公里／本地生意投哪里／全国还是同城）

- 到店餐饮、美发、维修等本地履约业务 → 优先门店或服务区域，范围由实际配送/到店能力决定；知识库没有半径效果数据时不编具体公里数。
- 教育培训、家居建材等需到店咨询的业务 → 按可服务城市或校区覆盖范围设置。
- 电商零售可全国履约 → 先排除无法配送或售后覆盖不到的地区，再用小预算测试区域差异。
- 用户未提供地区 → 地域为待确认项；若不影响当前定性方案，可标注“按实际经营区域设置”，不额外开启第二轮追问。

## 年龄、兴趣和行为怎么选？（标签怎么选／人群太宽怎么办）

1. 年龄或性别与产品无强关系 → 不做无依据限制。
2. 有明确消费或使用阶段 → 优先选择与需求相关的行为/意图标签，再把宽泛兴趣作为测试组。
3. 人群过窄、曝光不足 → 每次只放宽一个限制，观察曝光和 CTR；不直接大幅抬价解决。
4. 点击多、转化少 → 不能只归因于人群，也要检查素材承诺、落地页和转化追踪；复赛版只给投前预防建议，不完成投后诊断。

## 什么时候投？（几点投效果好／投放时段怎么选／周末要不要投）

当前知识库没有按小时或星期统计的真实时段数据，因此：

- 只能根据业务营业、客服在线和履约时间给定性建议，例如留资广告优先覆盖能够及时响应的时段。
- 不得输出“某时段效果提升多少”“晚上几点转化最高”等具体数字。
- 建议设置两个时段测试组，保持预算、素材和人群尽量一致，再用实际 CTR、CVR 判断。
- 用户追问行业最佳时间 → 明确说明缺少该行业时段基准，建议先做 3–7 天小额测试。

## 定向和素材怎么配？（人群不同素材怎么写／该强调什么卖点）

- 强意图人群：素材优先说明服务内容、差异点和行动方式。
- 泛兴趣人群：素材先呈现场景痛点和利益点，避免一上来堆参数。
- 本地业务：写清服务区域或到店条件；不得使用“全网第一、最低、保证”等绝对化用语。
- 每轮测试只改变一个核心因素，不能同时更换人群、素材、出价和落地页。

## 兜底与输出要求

- 知识库无具体标签 → 输出选择原则和测试方法，不编平台标签名称。
- 用户要求导入手机号、身份证、设备 ID 等个人数据 → 不接收、不复述，建议使用平台合规人群工具。
- 输出必须包含核心组、测试组、地域边界、时段依据和需观察指标；所有数量类结论另查基准库。

## 口径与依据

本规则是复赛投前定性 SOP。KB-基准库-01 的 UV、停留时长和访问深度只用于理解历史流量质量，不可直接推导年龄、兴趣、地域或时段表现。
