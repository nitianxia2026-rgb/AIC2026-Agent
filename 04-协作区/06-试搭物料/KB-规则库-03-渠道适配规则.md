# KB-规则库-03 · 渠道适配规则

> 管什么：在信息流、搜索、开屏三种广告形式中，按用户意图和预算给出主投及备选方案。
> 给哪个节点用：节点2（渠道判定）。版本：v0.1，2026-09-11。

## 信息流、搜索、开屏怎么选？（投什么广告／哪个渠道合适／新手从哪投）

1. 用户需要主动获客、留资或卖货，但潜在用户未必正在搜索 → 信息流优先；适合用内容和素材激发需求。
2. 用户提供的品类有明确搜索意图，如搬家、维修、培训报名、家装咨询 → 搜索可作为主投或辅助；关键词需求不明确时不夸大搜索效果。
3. 用户目标是大范围曝光，且预算高于 1000 元/天 → 可把开屏列为备选；预算较低或目标是直接转化 → 不优先开屏。
4. 用户要求具体媒体平台名称，而知识库没有平台实时政策和报价 → 只回答广告形式与平台类别，提醒结合所在地区和账户后台核对。

## 不同预算怎么搭配？（一天三百怎么投／小预算投哪里／预算够不够）

- 日预算低于 300 元：只选一个主渠道，优先信息流图文/横幅或意图明确的搜索；不做多渠道平均分配。
- 日预算 300–1000 元：选一个主渠道和一个小额测试方向；主渠道应与核心目标一致。
- 日预算高于 1000 元：可做信息流与搜索组合；只有曝光目标且预算充足时才把开屏加入测试。
- 用户只给总预算：先除以投放天数换算日预算；没有周期时按 7 天默认并声明假设。

预算档位只决定测试复杂度，不直接决定效果。任何曝光、点击和转化数量必须另查 KB-基准库-02 并调用计算器。

## 行业与渠道怎样配？（奶茶店投哪里／培训招生怎么投／家装获客）

1. 餐饮美食：本地半径内触达和短素材展示优先，通常先测信息流；若用户会主动搜索门店或品类，可加搜索。
2. 教育培训：留资链路较长，优先信息流获取线索，搜索承接明确课程需求；不得对升学、考试结果作保证。
3. 电商零售：新品或视觉型商品优先信息流；已有明确品牌词、品类词时可用搜索承接。
4. 本地服务：搬家、维修等强意图业务可优先搜索；美发、摄影、健身等内容驱动业务可优先信息流。
5. 家居建材：决策周期长，信息流用于种草和留资，搜索用于承接明确装修或产品需求。

以上是定性适配，不是平台排名；不得把飞桨数据中的匿名渠道或广告字段翻译成具体媒体。

## 学习期和测试期怎么处理？（刚开计划多久调整／数据不稳定怎么办）

1. 新计划先小额试投 3–7 天，观察曝光、CTR、CVR 和 CPA；这是测试建议，不是保证达到稳定状态的时间。
2. 同时只改变一个主要变量，如素材、定向或出价，便于判断原因。
3. 数据量不足时不凭一两天结果大幅扩量；先确认转化追踪是否正常。
4. 不知道渠道最低预算、准入或学习要求时 → 明确“以对应平台后台规则为准”，不得编造门槛。

## 无法推荐时怎么办？（行业不在五桶／信息不全／敏感行业）

- 品类不在五桶 → 选择最接近的业务类型并声明近似；差异明显时只给通用测试框架。
- 缺目标或预算 → 回到节点1一次问齐，不能跳到具体渠道结论。
- 医疗诊疗、药品保健、金融投资、彩票博彩、成人用品 → 不给投放渠道或出价方案，转为平台合规咨询建议。

## 口径与依据

信息流、开屏和搜索的 CTR、CPM、CPC、CVR 区间只从 KB-基准库-02 的同一分组读取。该库为合成行情口径，回答必须注明“按行业常见水平估算，接入真实投放数据后可校准”。
