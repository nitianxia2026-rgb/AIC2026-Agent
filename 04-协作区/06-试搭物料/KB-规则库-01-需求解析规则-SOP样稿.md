# KB-规则库-01 · 需求解析规则（SOP 样稿）

## 节点定位

- **何时用**：用户第一次描述需求时；用户补充信息后需要重新归类时。
- **输入**：用户自然语言原话。
- **输出**：四要素结构化结果——①行业桶 ②预算档位 ③目标类型 ④（可选）投放区域；缺项触发一轮追问。

## 行业归类五桶（含示例）

| 行业桶 | 包含（示例） |
|---|---|
| 餐饮美食 | 奶茶咖啡、小吃快餐、正餐、烘焙甜品、外卖店 |
| 教育培训 | 兴趣班、辅导托管、驾校、职业技能、考证培训 |
| 电商零售 | 淘宝/拼多多/微商店铺、直播带货、实体零售、零食日百 |
| 本地服务 | 家政维修、美甲美发、健身瑜伽、宠物、摄影婚庆、搬家的 |
| 家居建材 | 家具、家装、五金、灯具、建材批发 |

**归不到时**：问用户"您的生意最接近哪一类？"；**跨类时**：按主打产品/主营业务归类，一句话说明即可。

## 目标类型归类

| 用户说法 | 归类为 | 演算口径 |
|---|---|---|
| "要曝光/让更多人知道/打品牌" | 曝光 | 曝光量为主，CVR 不做主指标 |
| "加微信/留电话/咨询/私聊" | 留资（转化） | CVR＝留资÷点击 |
| "卖货/下单/成交" | 下单（转化） | CVR＝下单÷点击 |
| "到店/进店消费" | 到店 | 按留资近似演算，回答中声明这是近似 |

## 预算档位（影响渠道推荐）

| 档位 | 日预算 | 处理 |
|---|---|---|
| 低 | < 300 元 | 主推信息流图文/横幅；不建议开屏；建议先测试 3–7 天 |
| 中 | 300–1000 元 | 信息流为主 + 搜索辅助；可做小额组合测试 |
| 高 | > 1000 元 | 信息流+搜索组合；曝光型目标可考虑开屏 |
| 总预算制 | 用户只给总额 | 换算为日均（按计划投放天数），并说明换算 |

## 追问规则（最多一轮，一次问齐）

- 缺①②③任一项就追问，**一次问完所有缺项**，不挤牙膏。
- 整合话术模板："跟您确认三件事：您做哪一行/卖什么？每天大概投多少？想要的是曝光、加微信还是直接卖货？"
- 用户拒答或说"你看着办"：按 低预算 + 留资目标 默认走，并在【提示】段声明这两个假设。

## 敏感行业（不提供投放方案）

医疗诊疗、药品保健品、金融投资理财、彩票博彩、成人用品等：说明"这类行业投放有平台准入与合规限制，建议先咨询对应广告平台的行业政策"，不给出价与预算方案。

## 归类示例

- "奶茶店每天 300 块拉新" → 餐饮美食 / 低档 / 留资近似到店 → 走节点2（信息流优先）。
- "驾校招生，想要电话" → 教育培训 / 目标＝留资。
- "淘宝卖女装的，一个月 3000" → 电商零售 / 总预算换算 100 元/天 / 低档。
- "我们是做搬家的，想让周边人知道" → 本地服务 / 曝光型 → 地域定向建议优先。
