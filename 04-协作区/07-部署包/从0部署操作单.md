# 投手智囊出价API · 从0部署操作单

> 推荐路线：GitHub私有仓库＋Render Web Service。无需购买域名；Render生成的`https://xxx.onrender.com`就是稳定HTTPS地址。

## 第1段：创建GitHub私有仓库

1. 登录 <https://github.com/>。
2. 右上角`+`→`New repository`。
3. Repository name：`toushou-bid-sim-api`。
4. Visibility选择`Private`。
5. 不勾选README、`.gitignore`或License。
6. 点击`Create repository`。

## 第2段：上传最小部署包

打开本地目录：

`AI智能体大赛2026/04-协作区/07-部署包/投手智囊-出价API`

在刚创建的空仓库点击`uploading an existing file`，把这个目录内以下内容一起拖入：

- `bid_api.py`
- `bid_simulator.py`
- `verify_bid_api.py`
- `Dockerfile`
- `render.yaml`
- `.dockerignore`
- `.gitignore`
- `README.md`
- `outputs`文件夹及其中CSV

提交说明填`Initial API deployment`，点击`Commit changes`。

注意：不要上传整个比赛目录，不要上传任何API Key。

## 第3段：创建Render服务

1. 打开 <https://render.com/>，使用GitHub登录。
2. Render请求GitHub权限时，只授权刚才的私有仓库更安全。
3. Dashboard点击`New +`→`Web Service`。
4. 选择仓库`toushou-bid-sim-api`并点击`Connect`。
5. 填写：
   - Name：`toushou-bid-sim`
   - Region：选离比赛平台网络较近的可用区；不确定就用默认
   - Branch：`main`
   - Runtime：`Docker`
   - Instance Type：先选可用的最低档
6. 在Environment Variables添加：
   - Key：`BID_SIM_API_KEY`
   - Value：生成一段至少32字符的随机密钥，只保存在密码管理器中
7. Health Check Path填`/healthz`。
8. 点击`Create Web Service`或`Deploy Web Service`。

不要把密钥发到聊天、截图或写入文件。

## 第4段：确认部署成功

Render日志出现服务监听并显示`Live`后，页面会给出类似：

`https://toushou-bid-sim.onrender.com`

依次在浏览器访问：

1. `https://你的地址/healthz`：应返回`status: ok`；
2. `https://你的地址/openapi.json`：应看到OpenAPI JSON；
3. 检查OpenAPI中的`servers[0].url`与当前HTTPS地址一致。

如果免费服务休眠，第一次访问可能较慢；比赛前应主动唤醒并重新测试。

## 第5段：接入比赛平台API工具

1. 助手工具页→创建API工具；
2. 名称：`投手智囊-出价测试带`；
3. 选择“从URL导入”；
4. URL：`https://你的地址/openapi.json`；
5. 鉴权选`API Key`；
6. Header名称：`X-API-Key`；
7. Value填Render中相同的密钥；
8. 解析后确认只有`bid_simulate`、`post`、`/bid-simulate`；
9. 点“测试”并保存。

## 第6段：平台测试请求

正常请求：

```json
{
  "industry": "餐饮美食",
  "ad_type": "信息流广告",
  "billing_type": "CPM",
  "objective": "留资",
  "daily_budget": 500,
  "current_bid": 20,
  "spend_ratio": 0.6,
  "tracking_ready": true,
  "audit_status": "通过",
  "material": "图文"
}
```

应返回`status: ok`、推荐档和三种情景，并带“合成仿真”声明。

还要分别测试：删除`spend_ratio`、删除`tracking_ready`、把计费方式改成不匹配、填写错误API Key。这些场景应拒绝或报鉴权错误，不能编默认值。

## 回退条件

以下任一情况发生，正式助手不挂API，继续使用KB-04＋计算器：

- 部署不稳定或频繁休眠超时；
- OpenAPI解析出多余operation；
- 正常、缺参、鉴权失败测试没有全部通过；
- 比赛平台无法访问Render地址。
