# 曝光端基准与出价曲线（draft · 合成基准）

## 口径说明（人工补全后定稿）
1. 指标定义：CTR = 点击÷曝光；CPM = 千次展示成本；CPC = 单次点击成本；CVR = 转化÷点击。
2. 数据来源：**合成基准**——量级锚点按国内市场常识设定（见下表），每格 30 个伪样本加对数正态噪声取分位数；CVR 锚定来源：合成默认 2%（02 表存在，但口径不匹配/量级不适合，未引用）。不冒充真实大盘，答辩与对用户口径均须声明。
3. 分组维度：行业 × 广告类型 × 素材类型（搜索广告无素材维度，记'不限'）。
4. 分位数怎么读：P25–P75 = 建议区间；P50 = 典型水平。
5. 使用限制：合成数据仅用于'量级感与区间话术'，配合公式与计算器实算使用；禁精确预测表述。本表与真实转化端基准（02 表）口径不同——02 是飞桨历史渠道观测值，本表是行业常识锚点，两表各管各的，回答时各引各的表，不可互相换算。

## 合成假设表（可复核）

| 因素 | 取值 |
|---|---|
| 基础 CTR | 信息流 1.5% / 开屏 1.0% / 搜索 3.0% |
| 基础成本 | 信息流 CPM 18 元 / 开屏 CPM 35 元 / 搜索 CPC 2.5 元 |
| 素材倍率(CTR,成本) | 视频 (1.15, 1.05) / 图文 (1.0, 1.0) / 横幅 (0.7, 0.9) |
| 行业倍率(CTR,成本) | 餐饮美食 (1.05, 0.95)；教育培训 (1.1, 1.15)；电商零售 (1.2, 1.25)；本地服务 (1.0, 1.0)；家居建材 (0.85, 0.9) |
| 噪声 | 对数正态 σ=0.18；CVR σ=0.126；种子 42（可复现） |
| 出价曲线 | share(r)=r²/(r²+1)，r=出价/基准出价，基准价处份额 50% |

## 出价梯度曲线（所有组同形，相对倍数）

| 出价倍数 | 曝光倍数 | 成本倍数 | 转化倍数 |
|---|---|---|---|
| 1.0× | 1.00 | 1.00 | 1.00 |
| 1.5× | 1.38 | 2.08 | 1.38 |
| 2.0× | 1.60 | 3.20 | 1.60 |
| 2.5× | 1.72 | 4.31 | 1.72 |
| 3.0× | 1.80 | 5.40 | 1.80 |

读法：出价提到基准价 2 倍 → 预估曝光 ≈1.6 倍，但成本 ≈3.2 倍——**提价买量的边际成本上升很快**，这就是节点5要求做单调性自检的原因。注意：固定日预算时，实际曝光增幅会小于表中的曝光倍数（预算会先耗尽）。

## 演算示例（信息流 × 图文 × 本地服务，日预算 500 元）

- 查基准表：CPM≈18 元，CTR≈1.5%，CVR≈2%
- 正向：500÷18×1000 ≈ 2.78 万曝光 → ×1.5% ≈ 417 点击 → ×2% ≈ 8 个转化
- 逆向：目标 20 个留资 → 20÷2% = 1000 点击 → 1000÷1.5% ≈ 6.67 万曝光 → ×18÷1000 ≈ 1200 元/天
- 结论示例话术：'500 元/天大约带来 X–Y 个转化（建议区间），要稳到 20 个建议预算提到 1200 元左右或下调目标'
