# 交付收集

这里**只放当前任务的待填模板和新证据**。任务范围、步骤和验收标准统一看上一级 `02-当前阶段任务分配与群公告.md`，本目录不再维护第二套任务书。

## 固定目录

| 目录 | 当前要交 | 不要放 |
|---|---|---|
| `01-倪天夏-队长与平台/` | 平台配置、提示词变更、工具日志、演练证据 | 产品方案、队员测试原文 |
| `02-陈钰涛-QA与测试/` | 阻断回归、任务2/3对照、功能引导验收 | 自动化脚本、首轮已归档回答 |
| `03-徐毅-数据与算法/` | 出价仿真脚本交付说明、场景表、校验报告 | 外部大文件、已完成的数据初筛 |
| `99-归档/` | 队长验收后的完整批次，只读 | 当前还在修改的文件 |

## 交付规则

1. 不再新建“日期-当前交付”或新的个人目录；始终使用以上三个固定入口。
2. 原始回答、日志、截图、数据行数和哈希不可润色；没有证据写“待核验”。
3. 完成后由队长按 `YYYYMMDD-任务ID-主题` 整体移动到 `99-归档/`，并更新根目录 `00-进度看板.md`。
4. 测试脚本统一在 `03-数据脚本/`，知识库成品统一在 `06-试搭物料/`，交付区只收结果证据。
