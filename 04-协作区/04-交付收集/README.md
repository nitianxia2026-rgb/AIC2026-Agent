# 交付收集（交件放这里）

## 怎么交

1. 放进**自己名字的子文件夹**（没有就新建：`名字-内容`，如 `陈钰涛-测试集`）
2. 文件命名按《02-主题文件写作规范》：入库文档 = `KB-库名-序号-文档名.md`
3. 脚本产物（outputs/ 六个文件）打包（zip）放进 `徐毅-基准库/`
4. 交完在群里喊一声队长；**只放最终交件**，草稿和讨论留在本地/群聊

- `徐毅-基准库/` —— 9/10 交：探查报告 + 转化端基准 + 曝光端合成基准 + 出价曲线 + 校验报告（全 PASS）
