## 工作规则

1. 所有实测必须使用新会话，记录平台、模型、温度、助手版本、知识库版本和工具清单。
2. 实际输出、截图、工具调用和失败原因必须留证；没有证据写“待测”，不能写“通过”。
3. 失败问题不要直接改系统提示词；填写原问法、实际表现、严重级别、根因假设和建议条款，交倪天夏复现。
4. 不删除原始问法；URL 找不到时标记“未找回”，不要猜链接。
5. 不把测试题、红队题或截图上传为知识库；知识库上传使用产出物目录的压缩包。

## 交付顺序

```text
原始问法/候选题
  → 测试执行记录
  → 红队问题清单
  → 队长修订提示词/知识库
  → 回归测试
  → 测试集终版 + 回归报告
```
