# 协作区

> 队员从这里进入。当前任务只认一份，当前交付只用固定目录。

## 开工顺序

1. 看根目录 `../00-进度看板.md`：确认当前状态、依赖和问题。
2. 看 [02-当前阶段任务分配与群公告.md](02-当前阶段任务分配与群公告.md)：确认任务步骤、模板和验收。
3. 把新证据放入 [04-交付收集](04-交付收集/README.md) 的本人固定目录。

## 目录职责

| 路径 | 职责 |
|---|---|
| `02-当前阶段任务分配与群公告.md` | **唯一当前任务书**：任务ID、依赖、步骤、交付模板、验收门、群公告 |
| `02-主题文件写作规范.md` | 知识库和正式文档的格式规范 |
| `03-数据脚本/` | 数据、仿真和公开助手自动化测试代码；不放队员任务书 |
| `04-交付收集/` | 三人固定当前交付目录＋已验收批次归档 |
| `05-术语与数据流速查.md` | 数据口径和术语查询 |
| `06-试搭物料/` | 当前可上传/配置的提示词、KB、测试物料 |
| `99-归档/` | 已失效任务书、草稿、重复文件；只读追溯 |
