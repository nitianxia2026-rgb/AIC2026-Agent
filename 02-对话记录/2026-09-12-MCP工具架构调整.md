# 2026-09-12 · MCP 工具架构调整

## 本次决定

- 根据队长已完成的工具试验，复赛不再坚持“只挂计算器”这一过度保守方案。
- 计算器仍是唯一必挂的算术工具；Web Research、值得买、可视化图表列为 P0 MCP；思维导图、Word/PDF 导出、豆包文生图列为 P1 增强。
- API 暂不自建，避免外部端点、鉴权和比赛网络风险。
